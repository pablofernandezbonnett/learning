# Hiragana: leer antes que perfeccionar

El hiragana representa sonidos. Al principio, el objetivo no es caligrafía
perfecta: es poder leer despacio una frase conocida. Las vocales se pronuncian
de forma parecida al español: `a, i, u, e, o`.

## Tabla básica

| | a | i | u | e | o |
|---|---|---|---|---|---|
| | あ a | い i | う u | え e | お o |
| k | か ka | き ki | く ku | け ke | こ ko |
| s | さ sa | し shi | す su | せ se | そ so |
| t | た ta | ち chi | つ tsu | て te | と to |
| n | な na | に ni | ぬ nu | ね ne | の no |
| h | は ha | ひ hi | ふ fu | へ he | ほ ho |
| m | ま ma | み mi | む mu | め me | も mo |
| y | や ya |  | ゆ yu |  | よ yo |
| r | ら ra | り ri | る ru | れ re | ろ ro |
| w | わ wa |  |  |  | を o |
| | ん n |  |  |  |  |

Notas rápidas:

- `ら り る れ ろ` (*ra ri ru re ro*) es un toque breve entre `r` y `l`, no una
  `r` fuerte.
- `し` es `shi`, `ち` es `chi`, `つ` es `tsu` y `ふ` es `fu` suave.
- `を` suele sonar `o` y aparece sobre todo como partícula de objeto.
- `は` se pronuncia `wa` cuando marca el tema: `わたしは` (*watashi wa*).

## Sonidos que cambian una palabra

Las rayitas (`゛`) y el círculo (`゜`) cambian el sonido.

| Base | Con rayitas | Con círculo |
|---|---|---|
| か き く け こ | が ぎ ぐ げ ご (`ga gi gu ge go`) | |
| さ し す せ そ | ざ じ ず ぜ ぞ (`za ji zu ze zo`) | |
| た ち つ て と | だ ぢ づ で ど (`da ji zu de do`) | |
| は ひ ふ へ ほ | ば び ぶ べ ぼ (`ba bi bu be bo`) | ぱ ぴ ぷ ぺ ぽ (`pa pi pu pe po`) |

Combinaciones frecuentes: `きゃ kya`, `きゅ kyu`, `きょ kyo`; `しゃ sha`,
`しゅ shu`, `しょ sho`; `ちゃ cha`, `ちゅ chu`, `ちょ cho`.

## Tres marcas que importan

- `っ` (*sokuon*, “tsu pequeña”) corta la consonante siguiente: `ちょっと`
  (*chotto*, “un poco / espera”). Haz una pausa mínima antes de la segunda `t`.
- Una vocal repetida se alarga: `おかあさん` (*okaasan*, madre).
- `ん` es una `n` independiente: `にほん` (*nihon*, Japón).

## Pregunta y respuesta

> **おなまえは なんですか。**  
> *onamae wa nan desu ka?*  
> ¿Cómo te llamas?

> **わたしは パブロ です。**  
> *watashi wa paburo desu.*  
> Soy Pablo.

La pregunta contiene `は`, escrito *ha* en la tabla pero pronunciado `wa` aquí.

## Práctica de 2 minutos

Lee sin romaji, luego comprueba:

- `こんにちは` - *konnichiwa* - hola / buenas tardes.
- `ありがとう` - *arigatou* - gracias.
- `すみません` - *sumimasen* - disculpa / para llamar la atención.
- `にほんご` - *nihongo* - japonés.
