# Señalar cosas y lugares: esto, eso, aquello

Señalar bien es una de las formas más eficaces de sobrevivir cuando no sabes
una palabra. Estas cuatro familias se usan constantemente en tiendas, clase,
restaurantes y al pedir ayuda.

## Una cosa sin decir su nombre

| Japonés | Romaji | Español | English | Dónde está |
|---|---|---|---|---|
| これ | kore | esto | this | cerca de ti |
| それ | sore | eso | that | cerca de la otra persona o ya mencionado |
| あれ | are | aquello | that over there | lejos de ambos |
| どれ | dore | cuál | which one | pregunta entre varias cosas |

> **これは なんですか。**<br>
> *kore wa nan desu ka?*<br>
> ¿Qué es esto?
> English: What is this?

> **みずです。**<br>
> *mizu desu.*<br>
> Es agua.
> English: It is water.

> **どれですか。**<br>
> *dore desu ka?*<br>
> ¿Cuál es?
> English: Which one is it?

> **それです。**<br>
> *sore desu.*<br>
> Es ese.
> English: It is that one.

Para pedir señalando, usa el bloque que ya aparece en
[Pedir, comprar y comer](./06-pedir-comprar-comer.md): `これをください`
(*kore o kudasai*, esto, por favor).

## Antes de un nombre

`これ` (*kore*, esto) va solo. Si después dices el nombre, usa `この`
(*kono*, este/esta) antes de él. Las demás parejas siguen el mismo patrón.

| Va solo | Antes de un nombre | Romaji | Español | English |
|---|---|---|---|---|
| これ | この | kore / kono | esto / este, esta | this / this + noun |
| それ | その | sore / sono | eso / ese, esa | that / that + noun |
| あれ | あの | are / ano | aquello / aquel, aquella | that over there / that + noun |
| どれ | どの | dore / dono | cuál / cuál + nombre | which one / which + noun |

> **どの メニューが いいですか。**<br>
> *dono menyuu ga ii desu ka?*<br>
> ¿Qué menú prefieres / cuál te parece bien?
> English: Which menu would you prefer / which one is good?

> **この メニューが いいです。**<br>
> *kono menyuu ga ii desu.*<br>
> Prefiero este menú / este menú está bien.
> English: I prefer this menu / this menu is good.

No digas `これ メニュー` (*kore menyuu*): `これ` (*kore*, esto) ya ocupa el
lugar del nombre. Di `この メニュー` (*kono menyuu*, este menú).

## Sitios: aquí, ahí y allí

| Japonés | Romaji | Español | English |
|---|---|---|---|
| ここ | koko | aquí | here |
| そこ | soko | ahí | there |
| あそこ | asoko | allí / allá | over there |
| どこ | doko | dónde | where |

> **トイレは どこですか。**<br>
> *toire wa doko desu ka?*<br>
> ¿Dónde está el baño?
> English: Where is the restroom?

> **あそこです。**<br>
> *asoko desu.*<br>
> Está allí.
> English: It is over there.

> **ここで いいですか。**<br>
> *koko de ii desu ka?*<br>
> ¿Aquí está bien?
> English: Is it okay here?

> **はい、いいです。**<br>
> *hai, ii desu.*<br>
> Sí, aquí está bien.
> English: Yes, it is okay here.

## Regla corta para no mezclarlo

`これ / それ / あれ` (*kore / sore / are*, esto / eso / aquello) sirven para
una cosa. `この / その / あの` (*kono / sono / ano*, este / ese / aquel)
necesitan un nombre después. `ここ / そこ / あそこ` (*koko / soko / asoko*,
aquí / ahí / allí) son para lugares.

Con estas tres filas y un gesto ya puedes resolver muchas conversaciones. No
intentes elegir una expresión perfecta cuando tienes el objeto, el menú o el
mapa delante: señala y usa la frase corta.
