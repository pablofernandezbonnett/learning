# Adjacent Paths

This folder contains optional side paths.

These are not the default route for this repository.
Use them only when a real work need, role pressure, or interview pressure
appears around a specific area.

Why this folder exists:

- the main repo path should stay centered on senior Java backend growth
- some adjacent areas still matter, but not as the default study order
- keeping them here reduces noise without deleting useful material

## Use These Paths When

- you need deeper reliability ownership: [sre-from-backend-engineers.md](./sre-from-backend-engineers.md)
- you need wider solution and constraint framing: [solutions-architect-from-backend.md](./solutions-architect-from-backend.md)
- you want an AppSec-first study lane beyond the main backend roadmap: [appsec-for-software-engineers.md](./appsec-for-software-engineers.md)
- you need broader AppSec inside product delivery: [appsec-in-product-teams.md](./appsec-in-product-teams.md)

## Strong Default

- stay on the main roadmap first
- pick one adjacent path only when the gap is real
- do not run several side paths in parallel unless work clearly demands it

## Reusable Takeaway

> Adjacent paths are extensions, not the center of gravity. The backend core stays first.
