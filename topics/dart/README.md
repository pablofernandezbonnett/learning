# Dart

Use this block to refresh Dart before applying it in any framework. Start with the language feature that changes your model, then practise its use at an async or data boundary.

1. [Records, patterns, and class modifiers](./01-dart3-features.md): model a few values or a closed set of outcomes.
2. [Async, null safety, and collections](./02-async-null-safety-and-collections.md): handle one result, a sequence, absence, and small transformations.
3. [Tooling and JSON boundaries](./03-tooling-json-and-boundaries.md): run the feedback loop and convert external data into typed values.

For UI state and platform concerns, continue with [Flutter](../flutter/README.md).
